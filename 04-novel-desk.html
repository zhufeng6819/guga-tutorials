小说PLUS → AI小说家 工作台
怎么用这些工作台？统一四步：选工作台 → 建作品 → 填/选题材底稿 → 按该工作台的专属能力推进正文。四套引擎的能力不同，但入口、作品管理、导出方式完全一致，可以随时换台继续写同一部作品。

小说PLUS：作品与教程模板

先建作品，再挑底稿，最后按工作台能力往下写。

页面元素

元素说明
四个工作台标签AI_NovelGenerator / Long-Novel-GPT / OpenWrite / AI小说家；切换后描述与专属按钮随之变化，地址栏会带 ?tab=，可直接分享链接
导出 TXT / 保存修改右上角两个动作：把正文导出为 TXT、或保存当前改动
作品选择 + 新建作品下拉切换已有作品；「＋ 新建作品」展开表单：作品名（例：重生动书）→ 点创建
从教程模板选题（8 类 × 24 个）不会选题就点模板：现实生活 / 情感言情 / 年代历史 / 悬疑刑侦 / 古装权谋 / 玄幻武侠 / 幻想科幻 / 逆袭反转，每类 24 个
写作口诀页面顶部提示：日常场景 + 一个反常细节 + 钩子留在「谁在敲窗守钟声」，反常要具体（数字、日期、次数），答案最好落在人身上
  1. 顶部导航 小说PLUS，在下拉里选要用的工作台（也可直接点页面上的四个标签）。
  2. 点 ＋ 新建作品 → 填作品名 → 创建。
  3. 在教程模板选题里挑一个题材底稿（8 类 × 24 个），点开看结构示例，作为起稿参考。
  4. 回到该工作台的专属能力（角色状态表 / 层级流水线 / 正史分离 / 断点续传…）开始推进正文。
  5. 随时点 保存修改 落盘；完稿后 导出 TXT。
注意：模板里的示例选题（比如《我的前台是ink》《白月光在逃》《局长在吞金》《劫后重逢的aphore》《神经病少年的one夜》《说出口的restaurate》……）是题材与结构的示例写法，点开会带入作品表单作为创作底稿，请按自己的设定改写后再用。

工作台① AI_NovelGenerator

主打长篇连载的「记忆库」路线：写 17 万字不崩人设、不失忆。

官方定位

「长篇记忆库 → 写 17 万字不崩人设、不失忆」：设定工坊 → 生成世界观与人物档案 → 章节目录 → 逐章创作；角色状态表与伏笔账本自动追踪，章节篇幅自动更新前情；一致性审校检测剧情与人物矛盾。

四个专属按钮

按钮作用
角色状态表跟踪每个角色当前的状态（身份、关系、伤势、心理），避免人物前后不一
伏笔账本登记埋下的伏笔与「已兑现」标记，防止长篇里伏笔烂尾或遗忘
一致性审校检测剧情与人物矛盾，给出修订建议
新增章节在章节目录上继续加章，接着往下写
适合：日更连载、几百章的长篇。作者最容易崩的就是「人设漂移」和「伏笔烂尾」，这个工作台的四个按钮正好是冲着这两件事去的。

工作台② Long-Novel-GPT

层级流水线路线：创意 → 大纲 → 章节计划 → 正文逐层拆解重生成。

官方定位

「创意 → 大纲 → 章节计划 → 正文 层级流水线，逐层重生成；每层可用用户意见重生成；支持文本地图与「拆书」—— 导入已有小说，拆出人物关系、节奏类型与段落分镜建议。」

四个专属按钮

按钮作用
意见库生成沉淀作者意见并批量作用于生成过程，让 AI 越写越贴你的口味
层级流水线创意→大纲→章节计划→正文逐层推进，每层都能单独重生成
文本地图把全书结构可视化，掌握节奏与信息分布
拆书改编导入已有小说，拆出人物关系、节奏类型与段落分镜建议 —— 短剧化最实用的一步
它和短剧的关系：「拆书」能直接产出段落分镜建议，等于把网文直接改造成短剧分镜的素材。做短剧改编时，这一条比其它功能更值得先试。

工作台③ OpenWrite

最严谨的一条：AI 只能提案，人工确认后才进入「正史」。

官方定位

「canon 正史分离 —— 人物/世界观/文案先提案，人工确认后才成为 AI 不可背离的真源；Goethe 规划 + Dante 执笔双模式；六域审查（剧情/人设/设定/节奏/伏笔/氛围）输出逐条修订建议。」

四个专属按钮

按钮作用
canon 正史分离AI 写出的设定先进入「提案区」，你点确认入正史后才成为全书不可背离的设定
Goethe/Dante 双 AgentGoethe 负责规划（结构、大纲），Dante 负责执笔（正文），职责分离避免 AI 自说自话
提案强制所有改动必须走提案流程，防止 AI 悄悄改设定
六域审查剧情 / 人设 / 设定 / 节奏 / 伏笔 / 氛围 六个维度逐条给修订建议
适合：严肃题材、世界观复杂、需要多人协作审稿的团队。作者对设定有绝对控制权时，这套流程最稳。

工作台④ AI小说家

题材模板 + 滑动窗口上下文 + 断点续写，最适合日更爆款套路文。

官方定位

「六种题材模板（网文文学/爽打剧情/复仇/爽剧/暴爽）+ 滑动窗口上下文（近 3 章全文 + 近期弧线压缩），第 50 章也能与第 5 章同梗；断点续传一键写完下一章，单独可独立重成。」

四个专属按钮

按钮作用
6 种题材模板按题材套用章节节奏模板（如「模板控制每章字数与文风基调」）
滑动窗口上下文只带近 3 章全文 + 近期弧线压缩喂给模型，长篇也不超上下文
断点续传一键写完下一章；也可「仅重生成本章」或「查看/重生成第 N 章」
单独可重生成任意单章独立重写，不影响其它章节

四选一：怎么挑

工作台核心机制最适合
AI_NovelGenerator长篇记忆库：角色状态表 + 伏笔账本 + 一致性审校几百章日更连载
Long-Novel-GPT层级流水线 + 拆书改编 + 文本地图结构化创作、网文改短剧
OpenWritecanon 正史分离 + 双 Agent + 六域审查严谨设定、多人协作审稿
AI小说家题材模板 + 滑动窗口 + 断点续写套路爆款、日更不断更
接到短剧线上：小说PLUS 写完正文 → 右上角导出 TXT → 短剧导演台新建项目，把剧本粘贴进「原文与改写」→ 走「角色场景道具 → 分镜视频 → 成片合成」。若走改编路线，先用 Long-Novel-GPT 的「拆书改编」拿到段落分镜建议，再进导演台微调。

常见问题与检查清单

常见问题

现象原因与处理
生成没有反应 / 报模型错误检查 设置 → AI 服务 里的文本服务是否已启用并有 API Key；再回小说PLUS 重试
长篇写到几十章后开始重复、像换个人换用 AI_NovelGenerator 的角色状态表 + 伏笔账本，或 AI小说家的滑动窗口上下文
AI 擅自改了设定OpenWrite 的 canon 正史分离：所有改动先提案，人工确认才入正史
不知道从哪写起用「从教程模板选题（8 类 × 24 个）」挑一个底稿，再改写成自己的故事
正文怎么拿出来页面右上角导出 TXT；改动后记得点保存修改
想直接改成短剧Long-Novel-GPT 的「拆书改编」可输出人物关系、节奏类型与段落分镜建议；再把正文贴进短剧导演台做分镜
换工作台会不会丢稿四套工作台共用同一份作品列表，随时可切换；切换前记得保存修改

检查清单

  • 设置 → AI 服务中的文本服务已启用
  • 小说PLUS 已选中目标工作台（地址栏 ?tab=）
  • 作品已创建并命名
  • 已用教程模板选定题材方向（8 类 × 24 个）
  • 长篇项目已开启角色状态表 / 伏笔账本（AI_NovelGenerator）
  • 改编项目已跑过「拆书改编」并采纳分镜建议（Long-Novel-GPT）
  • 严谨项目已用 canon 正史分离固定设定（OpenWrite）
  • 日更项目已开启断点续传（AI小说家）
  • 正文已点「保存修改」，并「导出 TXT」备份
  • 小说文本已准备好，进入短剧导演台新建项目
