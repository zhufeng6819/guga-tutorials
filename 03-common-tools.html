常用工具图文教学

「常用工具」是咕嘎的独立工具台，不依附任何短剧项目，随用随做、随做随存。本教程覆盖 本地角色助手、qwen2.1 图像编辑器、视频画质增强、视频画质增强 v2 四个已上线工具， 并如实说明 场景助手 的当前状态与替代方案。所有界面图均取自软件真实运行界面（2560×1400 宽屏、深色模式）。

适用版本：咕嘎AI漫剧（Guga Studio）V3 入口：顶部导航 → 常用工具 阅读时长：约 12 分钟 前置条件：本地 ComfyUI 或已配置云端服务

常用工具页总览

同一套三栏骨架，八个标签页。左边填参数，中间看结果，右边管历史。

三栏结构（所有标签通用）

区域内容
左栏参数面板：模型、LoRA、提示词、尺寸、步数、模式选择等，随标签变化
中栏预览舞台：图片或视频大图，支持滚轮缩放 / 拖动平移 / 双击 100%，顶部可命名、发送至、刷新、关闭
右栏本页生成记录：状态统计（生成中 / 完成 / 失败）、缩略图、时长、存入素材库 / 打开文件 / 删除记录、收藏星标
为什么把工具单独拆一页？短剧流程里经常需要「先做一张角色图试试」「把一段旧视频提清晰」这类不依赖项目的活儿。常用工具就是为这些场景准备的：生成结果可一键存入素材库，也能发送至剧集直接用在剧集资产里。
1

本地角色助手

点选即成图的角色生成器：选风格 → 选角色定位 → 选图片类型，提示词自动组合，本地 ComfyUI 出图不花钱。

参数面板逐项

控件说明
模型默认 COMFYUI z_image_turbo（一键写入本地配置后可用）；带图标的是本地模型，右侧刷新按钮可重新拉取
LoRA下拉选择或「手动输入 LoRA 文件名…」（在 models/loras 下），可调 LoRA 强度并刷新列表
画面风格写实 / CG写实 / 3D仙侠 / 3D卡通
角色定位（点击套用预设）女主角、男主角、恶毒女配、反派男主、温柔男二、元气闺蜜、贵妇母亲、威严父亲、慈祥老人、萌娃小孩、保镖护卫、女仆管家、医生、警察、清纯学生、时尚主播……以及「自定义角色」
图片类型半身照 / 全身照 / 三视图 / 四视图
提示词选择风格+定位+类型后自动组合，可自由编辑；点「重新组合」按当前选项重写（会覆盖手改内容）
出图尺寸预设档位（入门预览级 4:3 / 社交媒体通用级 16:9 / 全高清级 16:9 / 2K超清级 / 专业创作级 4:3 / 4K旗舰级；竖屏另有 9:16、3:4、19.5:9 档），也可自定义宽高（64~4096，建议 8 的倍数）
采样步数按模型给出 4/6/8/12 等档位；步数越多细节越好、耗时越长
实时预览生成过程中在中间画布实时显示采样预览图
高级参数随机种子（-1 随机）、CFG 引导强度、负向提示词、采样器、调度器
开始生成提交任务，完成后出现在中间预览与右栏记录
  1. 顶部导航 → 常用工具 → 标签 本地角色助手。
  2. 选 画面风格 → 点 角色定位（如「女主角」）→ 选 图片类型（如「全身照」）。
  3. 提示词自动生成后，必要时手动补一句外形描述（发色、服装、道具），避免每次都抽同一个人。
  4. 选出图尺寸与采样步数，点 开始生成。
  5. 中栏预览满意后，点右上 发送至 发到剧集角色框，或 存入素材库 长期保存。
三视图 / 四视图是短剧里最省事的功能：一次出多角度，画风与服装完全一致，直接用作「角色资产」，后续分镜里的人脸就不会乱跳。

场景助手（未开发）

这是产品规划中的工具，当前版本尚未上线，界面里没有入口。本节说明它的定位与现在的替代做法。

当前状态（已在实际运行版本中核对）：常用工具的标签栏只有 8 个——本地角色助手、qwen2.1 图像编辑器、本地生图、云端生图、本地生视频、云端生视频、画质增强、画质增强v2，没有「场景助手」这一项；软件前端源码与全部语言包中也检索不到「场景助手」字样。因此它目前无法使用。

规划中的定位

  • 与「本地角色助手」对称：同样采用「预设分类 + 自动组合提示词 + 一键生成」的方式，用于批量产出场景图（室内 / 室外 / 街道 / 古代街市 / 山谷 / 宫殿……）。
  • 核心诉求：同一部戏的场景要能复用同一套空间布局与光线，因此每个场景会像角色一样有「场景定位预设 + 多角度图 + 英文描述锚点」。
  • 入库路径：生成后进入素材库，并可一键发送到剧集的场景资产，供分镜阶段作为参考图使用。

现在就能用的三种替代方案

方案做法适合
本地生图 / 云端生图标签切到「本地生图」或「云端生图」，在提示词里手写场景描述（主体 + 环境 + 光线 + 风格），生成后存入素材库单个场景、临时用
qwen2.1 图像编辑器用一张参考图做整图编辑 / 局部重绘，把同一张图派生出多个角度已有一张主图想改细节
短剧导演台 · 项目素材库在剧集的「素材库」标签里让 Agent 自动提取场景并出图，人工微调后存为项目资产推荐：场景与剧情强绑定，全片一致
不要去找一个不存在的按钮。如果手册或同事提到「场景助手」，请按上面第 3 条走「短剧导演台 → 项目素材库」的路线 —— 这条路不但现在可用，而且场景会和该剧的角色、分镜自动对齐，比独立的场景生成器更省事。

qwen2.1 图像编辑器

本地 Qwen-Image-2.1 驱动的修图台：整图编辑、局部重绘、移除对象、人脸替换四种模式。

四种编辑模式

模式做什么
整图编辑按提示词整体修改画面（换背景、改服装、改风格）
局部重绘在画布上框选一块区域，只重绘这一块（换衣服、修手、去掉路人）
移除对象移除方式：专用移除 LoRA（实验版）或仅提示词描述；可调消除强度
人脸替换人脸替换方式：BFS 身份增强（推荐）或仅提示词描述；可调身份增强强度

参数面板逐项（局部重绘）

字段说明
目标原图点击选择或拖入目标原图
选区边缘向外扩展 / 向内羽化；勾选「覆盖选区尺寸」可保证选区外像素保持不变、保留原图尺寸
选区像素要求例如「把选中的衣服纹理还原成细节」，描述越具体越准
局部重绘基础模型默认 768（推荐）；成品交付按图选 9 张贴图，提示词按 9 段描述画面与精度
采样步数 / 生成张数默认 40 步 / 1 张
实时预览生成过程中在画布实时显示采样预览
透明背景Qwen-Image-2.1 为蒸馏模型，原生 RGBA 输出，保存为透明底 PNG
高级参数随机种子（-1 为随机）、CFG 引导强度、负向提示词
  1. 常用工具 → 标签 qwen2.1 图像编辑器，模型选 qwen_image_2.1。
  2. 上传目标原图，再选模式（整图 / 局部 / 移除 / 人脸替换）。
  3. 局部重绘：在画布上拖框选区 → 写选区像素要求 → 选基础模型与步数 → 开始生成。
  4. 人脸替换：先传参考人脸，选 BFS 身份增强，调强度。
  5. 结果满意后 存入素材库 或 发送至 剧集。
注意 CFG：Qwen-Image-2.1 是蒸馏模型，CFG=1 时负向提示词不参与采样；需要负向提示词生效时把 CFG 调到大于 1（画质可能下降）。

视频画质增强（v1）

SeedVR2 超分 + RIFE 插帧，本地跑，不联网、不上传原片。

三个参数

参数说明
源视频上传或选择本地视频
增强方式超分 + 插帧（画面更清晰 + 动作更顺滑）；也可只做超分或只做插帧
插帧倍率如 2 倍帧率
目标清晰度如 720p（推荐·省显存）；越高越清晰、耗时越久
原理与排队：超分使用本机 SeedVR2，插帧使用 RIFE。它与生成任务共用同一队列，完成后在任务抽屉里取片。目标清晰度越高、视频越长，耗时越久。
v1 的取舍：只提供「超分 + 插帧」这一套固定组合，无法单独挑算法、也没有分辨率档位和编码质量可调。追求更多控制、更高画质上限，请用下一节的 v2。
5

视频画质增强 v2

四种增强方案 + 显存档位 + 编码质量，画质天花板更高，也更不容易卡死。

四种增强方案怎么选

方案特点推荐给
GAN 快速放大逐帧模型锐化，秒级出片，永不卡死老片抢救、时间紧
高码率保真不放大，仅重编码，画质与原片一致只想改善码率与兼容度
组合高清（推荐）GAN 预放大 + AI 精修，画质天花板正式交付
AI 精修SeedVR2 生成式，最自然，但较慢追求质感、不赶时间

其余参数

参数说明
分辨率档位8G 720p / 12G 720p / 16G 1080p / 24G 1440p —— 按自己的显存选，系统会显示预计时长与临时显存
插帧插帧 ×2（更顺滑）
编码质量中（平衡 · CRF 20）；CRF 越小越清晰、体积越大
预计时长 / 临时显存面板会直接给出「预计约 X 分钟 · 临时约 Y GB」的提示，按它排期
为什么 v2 更稳？GAN 路径把 960×544 放大到 1920×1088，避开了单次分辨率与插帧叠加造成的显存峰值；配合低 CRF 编码（20/16）和「逐帧模型」与「插帧」分离处理，能显著降低「跑一半崩掉」的概率。系统提示中也写明：跑完可看原片、随时缩放、可单帧对比。

生成记录与素材库互通

所有工具的产出都汇到右栏记录，并可一键入库或发到剧集。

右栏「本页生成记录」

  • 状态统计：生成中 / 已完成 / 失败 三个计数，失败任务可点「重新生成」按原参数重试
  • 每条记录：缩略图 + 名称 + 模型 + 耗时（如 5m22s），右侧可 存入素材库、打开文件（定位到磁盘）、删除记录、星标收藏
  • 刷新：右上角按钮同步最新任务状态
  • 发送至：本地生成的图片可直接发到剧集资产
推荐工作流：常用工具出图 → 存入素材库 → 在素材库里挑选、命名、收藏 → 发送到剧集的角色 / 场景框。这样素材集中在一处，剧集里不会到处散图。

常见问题与检查清单

常见问题

现象原因与处理
提示「尚未配置可用的生图/视频服务」去 设置 → AI 服务 添加并启用，或用 ComfyUI 一键配置写入本地服务
出图尺寸/步数被锁分辨率 0.6 以上、采样步数超过 8、生成分辨率超过 1920×1080、生成加速均属 VIP 功能，免费档用 8 步以内与较低分辨率
提示词被覆盖了「重新组合」会按当前选项重写提示词并覆盖手改内容；想保留手改就别点它
局部重绘边缘突兀勾选「覆盖选区尺寸」保持选区外像素不变，并适当调「选区边缘」的向外扩展 / 向内羽化
负向提示词不起作用Qwen-Image-2.1 是蒸馏模型，CFG=1 时负向提示词不参与采样，把 CFG 调到大于 1
画质增强任务排队很久与生成任务共用队列；面板会给出预计时长，可先降档位（8G 720p）或改用 GAN 快速放大
增强后文件找不到在任务抽屉取片，或在生成记录里点「打开文件」定位到磁盘
找不到「场景助手」该工具尚未开发，界面无入口；请用「本地生图」或「短剧导演台 → 项目素材库」

使用检查清单

  • 设置 → AI 服务已配置本地 ComfyUI 或云端生图服务
  • 选对模型：角色图用 z_image_turbo / qwen_image_2.1，修图用 qwen_image_2.1
  • 角色图已选画面风格 + 角色定位 + 图片类型，提示词手改过（外貌描述）
  • 尺寸档位与投放平台匹配（短视频 1080×1920 竖屏）
  • 免费档把采样步数控制在 8 步以内
  • 局部重绘先框选区再写像素要求
  • 画质增强已按显存选对档位（8G 720p / 12G 720p / 16G 1080p / 24G 1440p）
  • 生成的成品已「存入素材库」并命名
  • 需要的素材已「发送至」对应剧集资产框
