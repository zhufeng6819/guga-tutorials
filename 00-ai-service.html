AI 服务配置页总览

先认识这一页的整体结构：上方是「快速配置」，下方按 文本 / 图片 / 视频 三张卡片管理每一服务。

页面结构速览

  • 左侧导航：基础（AI 服务 / 本地Qwen 2.1 / 通用 / 视频画风 / Agent 配置 / 存储位置…）
  • 顶部快速配置卡：本地 ComfyUI 一键写入，官方标注「推荐」
  • 手动模板卡：文本 / 图片 / 视频 三个模板按钮，一键填好服务商与默认模型
  • 三类服务卡：每张卡右上角「＋ 新增」，卡片内是已配置的服务条目

官方提示（务必记住）

页面顶部写着：

“先用推荐模板快速落配置，再按服务类型微调。工作台创建集时会锁定所选图片和视频能力。”

也就是说：先在这里配好，再去短剧导演台创建集；一旦集建好，该集用的图片 / 视频能力就固定了，事后改配置不影响旧集。

三类能力分别是什么？
  • 文本：剧本改写、角色场景提取、分镜拆解等 Agent 文本能力
  • 图片：角色图、场景图与镜头图等静态图像生成
  • 视频：镜头视频直出生成，默认 Seedance 2.0

开启深色主题（界面外观）

本文所有截图均为深色模式。若你的界面还是浅色，按本节两步切换，长时间看图更护眼。

  1. 左侧导航点 通用。
  2. 找到 外观 卡片 → 主题模式 三个按钮中点击 深色。
  3. 下方 皮肤背景 可选预设图或纯色背景，不影响功能。
  4. 若想跟随系统自动切换，选「跟随系统」；主题立即生效并自动记住。
小技巧：软件顶部导航栏右侧也有一个主题快捷按钮（月亮图标），点击可在 浅色 → 深色 → 跟随系统 之间循环切换。

路线 A：本地 ComfyUI 一键配置（推荐）

有 NVIDIA 显卡（最低 8G 显存，推荐 11G 以上，24G 最佳）且本地已装好 ComfyUI 的用户，走这条路最省事：无需 API Key，生成全程本地运行。

  1. 解压 ComfyUI：建议把 comfyui 包解压到 D 盘 AI 文件夹下，例如 D:\AI\ComfyUI-MINIMAX。其他路径也行，改成自己的即可。
  2. 填目录：在 ComfyUI 目录 输入框填 ComfyUI 安装根目录，切勿使用中文路径。
  3. 确认端口：输入框下方是本地服务地址，默认 http://127.0.0.1:8188，与 ComfyUI 默认端口一致，一般不用改。
  4. 点「一键写入本地配置」：系统会自动保存，同时写入图片与视频两套配置。
写入后会发生什么？
  • 图片 → 服务名「本地图片 · ComfyUI Z-Image」，模型 z_image_turbo（默认）、krea2_turbo、qwen_image_2.1
  • 视频 → 服务名「本地视频 · ComfyUI MiniMax H3」，模型 minimax_h3（默认）
  • 生成的原始文件位于你填的目录下的 ComfyUI\output
路径要求：必须是 ComfyUI 的安装根目录（即里面有 ComfyUI\output 的那一层），不是 output 子目录，也不要指到工作流文件所在的 models 目录。

路线 B：手动模板快速填参

没有本地显卡、或想用云端 API / 中转站，就用手动模板：先选服务类型，再从模板填好 provider / base URL / model，你只需补 API Key。

点击模板按钮后的效果

模板服务商 providerBase URL预置模型
文本openai / geminihttps://geeknow.ai/v1、https://api.aixiai.top/v1、官方地址gemini-3-flash-preview、gpt-5.6-terra 等
图片gemini / openai / comfyui官方地址 / http://127.0.0.1:8188gemini-3-pro-image、gpt-image-2、z_image_turbo…

模板只是预填，随后弹出的表单仍可自由修改服务商、Base URL、模型与优先级。

三类能力分别怎么配

看懂一张配置卡片上的每个元素，后续排查会非常快。

卡片元素含义速查

元素含义怎么用
已配置 / 无密钥该服务是否填了 API Key。本地 ComfyUI 显示「无密钥」属于正常云端服务必须显示「已配置」
已停用该条目当前处于关闭状态，不参与调用用右侧开关打开即可
⭐ 模型标签该类型的默认模型，工作台优先调用点其他标签可把它设为默认
灰色模型标签备用模型，同类型内可随时切换点击即置顶为默认
http://…该服务的 Base URL排错时先核对这一行
开关 / 铅笔 / 垃圾桶启用停用 / 编辑 / 删除删除不可撤销，删前先确认没有集在用
测试仅文本服务提供：立即验证连通性改完 Base URL / Key 立刻点一次
为什么要分优先级？ 同类型可以存在多条启用配置（如本地 ComfyUI + 云端备用）。工作台会优先使用优先级数值最高的启用配置，失败时再回落到下一条 —— 这就是「本地兜底 + 云端保底」的用法。

新增 / 编辑服务配置逐项详解

在任意服务卡点「＋ 新增」，或点已有条目的铅笔图标，就会打开这个弹窗。

  • 顶部提示条默认推荐中转站 GeekNow 中转站，并附注册链接；提示可把 API Key 与 Base URL 填在下方「GeekNow 官方 API 与注册中转站」处，也可自行选择服务商。
  • 模板按钮Gemini 官方 / OpenAI 官方 / GeekNow 中转站 / AiXiAi 中转站。点一下即自动填入服务商、Base URL 与默认模型 —— 先点模板，再补 Key。
  • 配置名称自定义显示名，如「咕嘎默认图像服务」。同名不影响功能，但建议按用途区分。
  • 服务商下拉可选：gemini、openai、volcengine（火山引擎）、minimax、comfyui。
  • 优先级0–999，数值越高越优先。本地服务建议 98–99，云端备用建议 50 以内。
  • API Key密码框（sk-…）。云端服务必填；本地 ComfyUI 留空即可。
  • Base URL接口根地址。官方服务填官方地址，中转站填中转站地址（通常带 /v1），本地填 http://127.0.0.1:8188。
  • 模型输入模型名回车添加，首位为默认模型；点标签可置顶。点「刷新模型列表」可从当前 Base URL 拉取全部可用模型。
  • Temperature0–2 的小数，留空跟随服务商默认。若报 invalid temperature，按提示填固定值（如 kimi-k2 系只允许 0.6）。
  • 底部按钮测试配置：填完先测一次，端点会显示「已响应 / 未通过测试」；取消：不保存；保存：写入并出现在对应服务卡里。
操作顺序建议：模板 → 配置名称 → 服务商 → 优先级 → API Key → Base URL → 模型（可刷新）→ 测试配置 → 确认「端点已响应」 → 保存。

三套开箱即用方案

不知道选谁？按你的硬件条件对号入座。

方案适合谁配置动作成本
方案一
全本地		 有 NVIDIA 显卡（8G 显存起），追求不花钱、素材不出本机 路线 A 一键写入；文本能力另接一个云端文本 API 或本地模型 电费，无 API 费用
方案二
云端主力		 没有独显，或要更高质量的图/视频 手动模板：文本选 GeekNow / AiXiAi 中转站，图片选 Gemini 或 gpt-image-2，视频选 Seedance 2.0 或 MiniMax H3 按量计费
方案三
本地 + 云端双保险（推荐）		 正式生产，不想在赶稿时卡在模型上 本地 ComfyUI 优先级 99，云端同类型优先级 50；本地失效时自动回落云端 按量计费
方案三的做法：先按路线 A 一键写入本地配置；再点「＋ 新增」为同一类型加一条云端服务，把优先级填成 50（低于本地的 99）。两条都保持启用，工作台会优先用本地、出问题时用云端。

常见问题排查

① 底部提示「无法连接服务器，请检查网络或服务是否已启动」

说明本地服务没起来或地址不对。

  • 确认 ComfyUI 已启动，浏览器能打开 http://127.0.0.1:8188
  • 端口被占用时，改 ComfyUI 启动参数里的端口，并把设置里的地址改成同一端口
  • 地址写 127.0.0.1 而不是 localhost，避免 IPv6 解析差异

② 报错 invalid temperature

部分模型（如 kimi-k2 系）只接受固定温度。在弹窗 Temperature 处按提示填对应值（常为 0.6），不要留空。

③ 配置了但生成没变化 / 还是用老模型

  • 检查工作台选中的集是不是配置之前就创建的 —— 创建集会锁定当时的图片与视频能力
  • 在服务卡里确认目标模型标签上有 ⭐（默认模型）
  • 确认该条目开关是打开的（不是「已停用」）

④ 中转站能用官方模型，刷新模型列表却失败

「刷新模型列表」依赖端点的 /v1/models。部分中转站未开放该接口，此时手动输入模型名即可，不影响调用。

⑤ 想让本地 ComfyUI 走中文目录行不行？

不建议。官方明确提示不要用中文路径，容易出现工作流加载失败或节点报错，请迁移到纯英文/数字路径。

8

配置完成检查清单

照着勾一遍，确认 AI 能力已就绪，再去短剧导演台创建集。

  • 左侧导航已切到「AI 服务」页，三张卡片（文本 / 图片 / 视频）都能看到。
  • 文本：至少 1 条启用配置，标签显示「已配置」，默认模型带 ⭐。
  • 图片：至少 1 条启用配置，Base URL 正确，默认模型带 ⭐。
  • 视频：至少 1 条启用配置，默认模型带 ⭐。
  • 用本地 ComfyUI 的，确认浏览器能打开 http://127.0.0.1:8188。
  • 新增/编辑过的配置，点过「测试配置」并看到「端点已响应」。
  • 多配置共存时，优先级数值符合预期（本地 99 / 云端 50 之类）。
  • 确认所选模型的输出尺寸与后续项目需求一致（横屏 1080P / 竖屏 768P 等）。
  • 界面主题已切到「深色」（设置 → 通用 → 外观）。
  • 所有配置就绪后，再去短剧导演台创建集并锁定能力。
下一步：配置完成后回到顶部导航的 短剧导演台，新建集时选择图片能力与视频能力 —— 此时锁定的就是你刚配置好的模型。
