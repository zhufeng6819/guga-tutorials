素材库图文教学

咕嘎的素材库是一个专业素材工作台：多维筛选、日期相册、翻页直达，素材还能一键发送到剧集资产。 凡是常用工具、短剧导演台里生成的角色图、场景图、道具图，都会自动汇集到这里。本教程讲清三种视图怎么用、 素材卡片的每个按钮、角色音色库怎么绑、音色怎么进剧集、以及备份与迁移怎么做。 所有界面图均取自软件真实运行界面（2560×1400 宽屏、深色模式）。

适用版本：咕嘎AI漫剧（Guga Studio）V3 入口：顶部导航 → 素材库 阅读时长：约 10 分钟 适用对象：所有做图/做剧的用户

素材库总览

素材库是全软件的「素材总仓」：所有生成过的图片在这里集中管理，并可分发到剧集。

三种视图

视图适合什么时候用
按日期刚做完一批图，想按生成时间回溯；同一天的素材聚在一组
翻页浏览素材很多时，一页一页翻着看；卡片右上角标生成日期
角色音色管理角色音色（参考图 + 音色样本），供配音与台词驱动生成复用
素材从哪来？① 常用工具里生成后点「存入素材库」；② 短剧导演台里生成的角色图/场景图自动入库；③ 手动「上传素材」导入本地图片。删除记录不会删除磁盘文件，所以删错了还能从「素材库所在文件夹」里找回。

页面结构与顶部工具条

整页分三层：标题与操作区 → 筛选条 → 内容区（三种视图）。

顶部按钮逐个说明

按钮作用
搜索名称 / 提示词 / 模型一个搜索框同时匹配素材名称、提示词文本、生成模型三处
素材库所在文件夹打开素材在磁盘上的真实目录
刷新重新扫描目录、拉取最新素材
上传素材批量把本地图片导入素材库
导入备份从备份文件恢复素材记录
导出备份把当前素材库导出成备份文件

筛选条四个维度

维度可选项
分类男人 / 女人 / 老人 / 小孩 / 妖怪 / 野兽 / 风景 / 建筑 / 室内 / 道具 / 其他
画幅横屏 / 竖屏 / 方图
风格写实 / CG写实 / 3D仙侠 / 3D卡通
模型按生成模型筛选（如 qwen_image_2.1、z_image_turbo）

筛选条右侧实时显示「共 N 条」，多个维度可叠加。筛选后切到「翻页浏览」可以一页页核对。

视图① 按日期

默认视图：按生成日期分组，像相册一样回看每天产出的素材。

一张素材卡片上有什么

  • 缩略图：点开可看大图预览
  • 右上角标签：素材分类（如「横屏」）与收藏星标
  • 名称 + 模型 + 尺寸：如「真人电影实拍质感，写实CG电影范…　qwen_image_2.1　1920×1088」
  • 提示词摘要：鼠标悬停可看完整提示词
  • 底部操作条：发送到剧集 / 复制 / 编辑 / 收藏 / 删除（详见第 5 节）
3

视图② 翻页浏览

素材量大时的翻页模式：网格更紧凑，右上角直接标日期，底部翻页。

两种视图怎么选？「按日期」适合按批次找素材——"那天做的那批角色图"；「翻页浏览」适合按张数挑素材——"一百张里挑三张"。筛选条在两种视图里都生效，可以先筛再翻。
4

视图③ 角色音色

把角色的参考图与音色样本一次绑定，之后配音、台词驱动生成时全项目复用。

新增音色的四个字段

字段说明
角色名例如「咕嘎」
参考图该角色的形象图；上传后与音色绑定
音色样本5~10 秒干净人声（wav/mp3）效果最佳，AI 会克隆该角色音色
备注可选，说明角色语气或用途
音色怎么用？在短剧导演台的分镜工作台里，参考音色（对白音色克隆）最多可添加 3 个；填写「对应角色名」（如：主角），H3 就会依据参考音频克隆角色音色并原生生成对白口型；也可以选 高保真 CosyVoice3 先听后拍。素材卡片右下角还能绑定音频并直接试听。
5

素材卡片与按钮

把鼠标移到卡片上，底部一排按钮全部出现。

五个按钮

按钮作用
发送到剧集把素材指派到某个剧集某个集的角色形象框
复制复制素材到素材库（生成副本），原件保留
编辑修改名称、提示词等素材信息
收藏（星标）加入收藏夹，常用素材单独成集
删除（垃圾桶）删除记录，会二次确认；磁盘文件保留
删除语义：提示写得很清楚 —— 「确定删除该素材吗？文件保留在磁盘，仅移除记录」。所以删错了不用慌，到「素材库所在文件夹」把文件拷回来再上传即可。

发送到剧集

素材库与短剧导演台之间的关键通道。

  1. 在素材卡上点 发送到剧集。
  2. 选择剧：下拉里挑目标短剧。
  3. 选择集：挑具体某一集；若提示「该剧暂无集」，先去导演台把集建出来。
  4. 选择要设置形象的角色：该集已有角色会被列出；已设过形象的会标「已有形象」。
  5. 点 确认发送，提示「已发送到角色形象框，刷新剧集页即可看到」。
典型用法：在常用工具或素材库做出满意的角色三视图 → 发送到剧集 → 指定集 → 指定角色。此后该角色在分镜里都会以这张图为形象锚点，人脸跨镜头保持一致。
7

收藏夹

把常用素材挑出来单独成集，顶部导航「素材库」下拉里直接切到收藏夹。

收藏夹怎么用

  • 加入：卡片上点星标（图标由空心变实心）。
  • 移出：再点一次星标即可取消。
  • 进入：顶部导航「素材库」悬停展开下拉 → 选「收藏夹」（地址为 /library?view=favorites）。
  • 收藏夹里的素材同样可以发送、编辑、删除，操作与主库完全一致。
8

上传、备份与迁移

素材库不只是"看"，还可以"进"和"搬"。

上传素材

  • 点顶部 上传素材 → 选择本地图片（支持多选）。
  • 上传成功会有提示条（成功 N 个 / 失败 N 个与原因）。
  • 导入的素材会按画面自动判分类别与画幅，可再手动改名与补提示词。

导入备份 / 导出备份

操作说明典型场景
导出备份把当前素材库导出成一个备份文件换电脑、重装系统前存档
导入备份从备份文件恢复记录；会提示「成功 N 条 / 跳过 M 条」新机器恢复素材库

备份文件格式不对时会提示「备份文件格式不正确」，别强行改后缀，按软件导出的文件来即可。

素材库所在文件夹

点顶部 素材库所在文件夹 直接打开磁盘目录。想批量重命名、换分辨率、或把删除的记录找回，都在这个目录里操作最方便。

常见问题与检查清单

常见问题

现象原因与处理
素材库里看不到刚生成的图常用工具生成后要点存入素材库；导演台产出的会自动入库。入库后点刷新再找
发送剧集时提示「该剧暂无集」先去短剧导演台给该剧创建集，再回来选择
发送后剧集里看不到按提示刷新剧集页；确认发送的集与角色正确
删掉的素材还能找回吗能。删除只移除记录、文件保留在磁盘，到「素材库所在文件夹」找回再上传
搜索不到素材搜索同时匹配名称、提示词、模型；若搜不到，先清掉筛选条上的分类/画幅/风格/模型条件
导入备份没反应确认是本软件导出的备份文件；格式不对会提示「备份文件格式不正确」
音色试听没声音检查音色样本是否已上传（未绑定的会显示「未绑定音色样本」），再点试听
角色在剧集里长得不一样在素材库把定妆照发送到剧集指定角色，作为该角色的形象锚点

素材库使用清单

  • 设置好生成模型（角色图 / 场景图 / 道具图各有各的模型）
  • 在常用工具生成后点「存入素材库」，不要只留在本地
  • 用分类 / 画幅 / 风格 / 模型四个维度筛选，快速定位
  • 重要素材（定妆照、场景底图）打星标进收藏夹
  • 给素材改好名字与提示词，方便日后搜索
  • 定妆照「发送到剧集」指定集与角色，锁定形象锚点
  • 常用角色在「角色音色」里绑好参考图与音色样本
  • 删素材前先确认（记录可删，文件保留）
  • 换电脑前先「导出备份」
  • 大批量处理素材时切到「翻页浏览」，一屏一屏核对
